The look mirrors the portfolio at **leonardolopes.tech**: neon blue on midnight, glass cards, uppercase mono eyebrows.


## How to update

1. Edit the data in `scripts/build_svgs.py`, never a generated SVG.
2. Run `python3 scripts/build_svgs.py`.
3. Verify (see below).
4. Commit `scripts/` + `assets/`.

Where everything lives in the script:

| What to change | Where |
|---|---|
| Colors / fonts | constants at the top (`MIDNIGHT`, `CARD`, `FG`, `MUTED`, `COBALT`, `NEON`, `NEON_SOFT`, `SANS`, `MONO`) |
| Hero name, title, tagline | `build_hero()` |
| Frontend/Backend/Mobile cards | `cards` in `build_layers()` |
| Current role, description, metrics (~59%, Zero downtime, 6+ years) | `desc` and `stats` in `build_about()` |
| Experience | `jobs` list in `build_experience()`: `(period, project, role, line1, line2, via_buildbox)` |
| Technologies | `STACK` (category → file names in `assets/source/icons/`) |
| Dark icon that disappears on midnight | add its name to `DARK_ICONS` (rendered as a light silhouette) |
| Animation loop speed | `CYCLE` (seconds) |

### Convert oklch → hex

`globals.css` uses oklch, and the SVGs need hex:

```bash
python3 - <<'EOF'
import math
def oklch(L,C,h):
    h=math.radians(h); A=C*math.cos(h); B=C*math.sin(h)
    l=(L+0.3963377774*A+0.2158037573*B)**3; m=(L-0.1055613458*A-0.0638541728*B)**3; s=(L-0.0894841775*A-1.2914855480*B)**3
    rgb=(4.0767416621*l-3.3077115913*m+0.2309699292*s, -1.2684380046*l+2.6097574011*m-0.3413193965*s, -0.0041960863*l-0.7034186147*m+1.7076147010*s)
    f=lambda x: round(255*max(0,min(1,(1.055*x**(1/2.4)-0.055) if x>0.0031308 else 12.92*x)))
    return '#%02x%02x%02x'%tuple(map(f,rgb))
print(oklch(0.107, 0.011, 266.5))  # --background -> #030407
EOF
```

## SVG rules (gotchas)

- **No external URLs inside the SVGs.** GitHub serves README SVGs as `<img>` (via camo), which blocks external requests. Images and icons are embedded as data URIs (`data_uri()`), and web fonts can't be loaded with `@import`.
- **The static value must be the final state.** The animations (`loop`, `fade`, `rise`, `enter`) go from the initial to the final state and repeat every `CYCLE`. Give each element its *final* value as the static attribute (e.g. `opacity="1"`), so renderers without SMIL show the finished design.
- **Text width is estimated** (`wrap()` and `pill()` use per-character ratios). Mono text inside a fixed-width box needs `textLength` + `lengthAdjust="spacing"`, or it overflows in wider fonts. This already happened with the hero pill. Include `letter-spacing` in the math.
- **Font:** declared as `Inter`, falling back to system fonts. Don't embed the font file (too heavy).
- **Small text:** GitHub renders the README about 830px wide, roughly 0.7× the 1200px SVG. Keep SVG font sizes at 13px or more.
- **Size:** `stack.svg` is about 200 KB because of the embedded icons. Don't let it grow much past that.
- **IDs** (`blur`, `glow`, `glassEdge`, `whiten`) are local to each file. They don't clash because each `<img>` is isolated.

## Verification (required before committing)

```bash
python3 scripts/build_svgs.py
for f in assets/*.svg; do xmllint --noout "$f" || echo "BAD $f"; done
```

Visual preview. Headless Chrome doesn't run SMIL and captures frame 0, so strip the animations before taking screenshots:

```bash
OUT=/tmp/readme-preview; mkdir -p $OUT
for f in hero layers about experience stack cta; do
  h=$(grep -o 'height="[0-9]*"' assets/$f.svg | head -1 | tr -dc 0-9)
  perl -0pe 's/<animate(Transform)? [^>]*\/>//g' assets/$f.svg > $OUT/$f.svg
  "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
    --hide-scrollbars --window-size=1200,$h --screenshot=$OUT/$f.png "file://$OUT/$f.svg"
done
```

Check the PNGs for text overflowing a box or card, icons invisible on the background, and overlapping elements. To see the real animation, open the `.svg` directly in a browser.

## Automated widgets (`.github/workflows/profile.yml`)

- Runs daily at 06:00 UTC, on `workflow_dispatch`, and on pushes that change the workflow or `profile-3d.json`.
- **3D contrib** (`yoshi389111/github-profile-3d-contrib`): uses the colors in `.github/profile-3d.json` and writes `assets/generated/profile-3d.svg`.
- **lowlighter/metrics**: languages plugin only, in the `America/Sao_Paulo` timezone. Writes `assets/generated/metrics.svg`. The `habits` and `achievements` plugins are broken upstream (as of Nov 2026: GitHub dropped commit payloads from push events and sunset Projects classic). They render "Unexpected error", so don't re-enable them without checking the upstream repo first.
- Requires the **`METRICS_TOKEN`** secret (classic PAT with `read:user` + `repo`). Without it, metrics fails.
- Both run in a single job so their auto-commits don't conflict.
- The snake (Platane/snk) was removed. If the `output` branch still exists, it's a leftover from it and can be deleted.
