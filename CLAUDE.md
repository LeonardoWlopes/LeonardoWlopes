### Convert oklch → hex

```bash
python3 - <<'EOF'
import math
def oklch(L,C,h):
    h=math.radians(h); A=C*math.cos(h); B=C*math.sin(h)
    l=(L+0.3963377774*A+0.2158037573*B)**3; m=(L-0.1055613458*A-0.0638541728*B)**3; s=(L-0.0894841775*A-1.2914855480*B)**3
    rgb=(4.0767416621*l-3.3077115913*m+0.2309699292*s, -1.2684380046*l+2.6097574011*m-0.3413193965*s, -0.0041960863*l-0.7034186147*m+1.7076147010*s)
    f=lambda x: round(255*max(0,min(1,(1.055*x**(1/2.4)-0.055) if x>0.0031308 else 12.92*x)))
    return '#%02x%02x%02x'%tuple(map(f,rgb))
print(oklch(0.107, 0.011, 266.5))  # --background -> #030407
EOF
```

## Design rules to keep (from the portfolio's DESIGN.md)

- **Light means production.** Saturated light (neon fill, glow, lit dot, filament) only marks live work: the current role, the current Buildbox lane, Callink. Past work stays unlit (`foreground/45` bars, muted text).
- **No cobalt or neon small text.** Use `NEON_SOFT`, `FG` or `MUTED` for text. Cobalt is only used for light pools and lines.
- **Figures in mono.** Every number (metrics, years, dates, periods) is set in Geist Mono with `tnum` + `zero` (`mono()` helper). Words stay in Geist. Mono uppercase words are allowed only on the badge.
- **Glass only over light.** Over plain midnight use hairlines (white 8–12%). The hero has a single light CTA, "Know more ↗" (owner asked to drop "Download resume" and "Start a project"); the whole hero image links to the site.
- **No grey drop shadows, no photos.** Depth comes from light (blur glows). The only imagery is the caricature and the signature.
- **Easing** `cubic-bezier(0.16, 1, 0.3, 1)` for entrances.

## SVG gotchas

- **No external URLs inside the SVGs.** GitHub serves README SVGs as `<img>` (via camo), which blocks external requests. The brand vectors are inlined (portrait as a `<mask>`, signature as nested `<svg>`). Web fonts can't load either: Geist falls back to the system UI font.
- **Animations are CSS**, defined in `BASE_CSS` (`.in`, `.draw`, `.pulse`, `.float`, `.drift`, `.rise`) and looped every `CYCLE` seconds. They are gated on `@media (prefers-reduced-motion: no-preference)`, as the design system requires. The static markup must be the **final frame**, so no-motion and no-CSS renderers show the finished design.
- Apply animation classes only to wrapper `<g>` elements that have no `transform` or `opacity` attribute. CSS keyframes override both attributes: an `.in` class put directly on the slab's glow ellipse (`opacity=".32"`) once animated it to full opacity, turning it into a solid blue block. Use `transform-box: fill-box` for local origins (`.float` on the badge mirrors the site's `portrait-drift`).
- **Text width is estimated** (`wrap()` and the link arrow use per-character ratios). Check the screenshots for overflow after any copy change.
- **Small text:** GitHub renders the README about 830px wide, roughly 0.7× the 1200px SVG. Keep font sizes at 13px or more.
- Keep `scripts/build_svgs.py` runnable on Python 3.10+ with only the stdlib (the workflow pins 3.12).

## Automated widgets (`.github/workflows/profile.yml`)

- Runs **every Monday at 06:00 UTC** (03:00 in São Paulo), on `workflow_dispatch`, and on pushes that change the workflow, `profile-3d.json` or `scripts/build_svgs.py`.
- Steps:
  1. Rebuild the README cards, so the career length and ruler stay current.
  2. Generate the **3D contrib** calendar (`yoshi389111/github-profile-3d-contrib`) → `assets/generated/profile-3d.svg`.
  3. Run **lowlighter/metrics** (languages plugin only, `America/Sao_Paulo`) → `assets/generated/metrics.svg`.
  4. Commit everything under `assets/`.
- The metrics `habits` and `achievements` plugins are broken upstream (as of Nov 2026: GitHub dropped commit payloads from push events and sunset Projects classic). They render "Unexpected error"; don't re-enable them without checking upstream.
- The GitHub API sometimes returns no language data. The workflow keeps the previous `metrics.svg` when the new render has no language rows.
- Requires the **`METRICS_TOKEN`** secret (classic PAT with `read:user` + `repo`).

### Checking an animation frame by frame

Headless Chrome won't advance CSS animations reliably, so freeze them at a given time `T` (seconds) with a negative delay and a paused play state, then screenshot:

```bash
T=1.8; python3 - "$T" /tmp/hero-$T.svg <<'EOF2'
import re, sys
t = float(sys.argv[1]); s = open('assets/hero.svg').read()
s = re.sub(r'style="animation-delay:([\d.]+)s"', lambda m: f'style="animation-delay:{float(m.group(1)) - t:.2f}s;animation-play-state:paused"', s)
open(sys.argv[2], 'w').write(s)
EOF2
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --hide-scrollbars \
  --window-size=1200,1020 --screenshot=/tmp/hero-$T.png "file:///tmp/hero-$T.svg"
```
